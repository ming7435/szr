# 数字人 Implementation Plan

> 本计划记录初始照片朗读版本。用户随后追加实时 AI、最新图片与原声录音要求，最终范围和执行记录见 `../../技术方案.md`、`../../progress.md` 与 `README.md`。

> **For agentic workers:** Use native execution in the current session. Steps use checkbox syntax for tracking.

**Goal:** 照片里的本人在本地交互页面里朗读用户输入的中文文案。

**Architecture:** 本地 Node HTTP 服务调用 Windows 语音合成并返回音频与时间轴。静态页面用 Canvas 展示原图与局部表情，音频播放驱动动画和字幕。

**Tech Stack:** Node.js built-ins, Windows System.Speech, HTML, CSS, Canvas, Web Audio.

**Spec:** ../specs/2026-10-08-avatar-design.md

## Global Constraints

- 服务仅绑定 127.0.0.1。
- 每次朗读最多 1200 字。
- 原照片决定人物外貌；系统声音不代表本人声音。
- 不声称三维建模、声音克隆或智能问答。

## Review Focus

- 空白、超长、错误类型的文案不会调用合成器。
- 未知音色、无效语速不会执行任意命令。
- 停止合成中的请求不会导致过期音频开始播放。
- 暂停时音频时间、字幕和嘴型停止推进。
- 手机窄屏布局、系统语音失败和图片加载失败可用。

**Interfaces:** GET /api/voices; POST /api/speak with {text,voice,rate}; response {audio,dataUrl,duration,words,visemes}; createServer().
