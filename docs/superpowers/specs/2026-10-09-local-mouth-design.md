# 本机实时口型

用户已明确选择：先接实时口型，继续完善表情；仅使用当前 Windows / Intel Arc 核显电脑。照片保持当前办公室照片，声音固定豆包复刻 S_dCBmWoBh2，不显示对话文字。

可行性实测：OpenVINO 2024.6 的 Wav2Lip 96 FP16 在本机 GPU 推理约114 FPS，合成诊断视频约58 FPS。只能证明本机口型计算速度，尚未证明浏览器端实时声画、打断或自然表情。该模型仅用于个人和研究测试，不能用于企业商业接待。

本机 Python 持续接收24kHz PCM，每40ms音频配一个实际推理出的嘴部画面，约219ms后视音频用于特征。传回同一包中的原始PCM字节和嘴部JPEG，不另行生成或变换声音。浏览器按唯一的AudioContext时钟排声音并绘制嘴部，原图其他区域保留。收到停止、插话或断线立即停音并恢复原图，过期推理和异步解码结果不可恢复。

每次回答最多90秒，解码播放提前量最多2秒；只允许一个本机人像连接，外部Host/Origin拒绝。模型故障要显示失败，不声称口型已接通或悄悄换声音。后台在首次连接时加载并热身，后续复用。

本轮交付个人测试口型，完整眨眼、表情、头部动作仍未实现；不得用CSS动效冒充真实面部模型。未来企业部署须更换可商用模型。
