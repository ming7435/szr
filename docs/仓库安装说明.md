# 从仓库安装与本机配置

本仓库包含景区讲解员网页、实时语音桥接、照片驱动的口型和眼眉/头部/手腕代码、当前人像与照片绑定的动作素材，以及承德避暑山庄资料。默认景区资料由 `knowledge/` 提供，后续景区扩展与 RAG 规划见对应文档。

## 基础启动

使用 Node.js 20.12 或更高版本，在项目目录执行：

```powershell
npm ci
npm start
```

浏览器打开 `http://127.0.0.1:4173/`。Windows 也可以运行 `启动数字人.cmd`。界面仅提供语音交互，须在本机设置中配置实时语音服务和自己的复刻音色；服务密钥不要写入源码或提交到 Git。

## 仓库与本机文件的边界

`.private/` 中的服务凭据、复刻音色配置、账号授权、客户记录和本机偏好均不上传；`.env`、`.env.local` 及其他环境私密文件同样排除，只有无密钥的 `.env.example` 纳入版本管理。上传声音及降噪版本 `public/assets/voice-reference*` 保留在原电脑，需要使用旧的本机音色转换时自行放入相应路径。当前云端复刻声音使用本机配置的音色 ID；上传声音文件不是前端运行的必需素材。

`node_modules/`、`.runtime/`、`output/`、浏览器测试报告和 Python 缓存不上传。新的电脑不会自动拥有原电脑的模型、运行环境或服务账号：本机神经口型需单独准备 Python/OpenVINO 环境和与当前人像匹配的 Wav2Lip 模型，参考 [本机口型说明](local-mouth.md)、`requirements-avatar.txt` 和 `scripts/` 中的模型准备代码。原电脑的这些文件继续保留，Git 上传不会删除它们。

当前肢体动作限交握双手与局部前臂的小幅变形，完整自由手势尚未实现；口型模型及相关第三方素材的使用范围需遵守其各自许可。仓库代码不包含云服务试用额度或授权。
