# 景区旅游数字讲解员：场景演示

当前版本在 Windows 本机运行，使用墨绿色外套、白色上衣的园林讲解员形象、既有实时语音服务与用户的复刻音色。回答通过声音播放，页面不显示识别文字、回答字幕或文字聊天。口型模型已根据新照片重新构建，眉眼、面部和照片手部动效也绑定新版人像。背景为 AI 生成的园林氛围，不是核实过的避暑山庄实景；讲解资料仍来自下述景区官方来源。

页面只保留一个「旅游景区」入口，身份为景区讲解员，不使用固定个人姓名。景点讲解、游览路线和游客服务共用一套景区资料。页面称呼和语音自我介绍按当前景区及讲解职责展开。旧版自动加入的个人姓名前缀会在刷新时清理，原有讲解风格与回应节奏保留；新规则在重新开始对话后生效。

前端现在以当前景区名称展示导航、主标题、唯一景区卡片、对话标题和浏览器标题。承德避暑山庄使用园林配色、“宫苑山水，边走边听”介绍与烟雨楼提问示例；更换景区名称后改用通用提示，不显示承德专属内容。项目已按用户要求启动，并在更换人像后重启加载新版素材。当前桌面与移动预览见 `output/guide-scenes/`。

## 打开与对话

1. 服务未启动时，双击项目里的 `启动数字人.cmd`。
2. 用 Chrome 或 Edge 打开 <http://127.0.0.1:4173/>；旧页面按 Ctrl+F5 刷新。
3. 点击「开始对话」，允许麦克风，然后直接说话。说完停顿后等待声音回答；可以插话，或使用原有的静音、打断和结束按钮。
4. 修改并保存景区资料会先结束当前会话，再次点击「开始对话」使用新资料。

当前已配置实时语音服务和用户的复刻音色，无需 ChatGPT 登录，也不需要重新创建声音。服务异常会显示实际错误，不自动换用另一种声音。

当前发声规则要求吐字清晰、节奏利落、短句短停顿、句尾自然收住，避免撒娇语气与故意拖音。原来保存的表达偏好继续保留，但需遵循该发声规则；原复刻音色不变。规则通过新会话生效，实际语气和听感仍需试听确认。

## 更新或更换景区资料

打开右上角「景区与分身设置」，编辑统一使用的以下资料：

- 景区名称与简介。
- 景点与旅游讲解资料。
- 推荐参观路线。
- 参观与服务信息，例如已确认的开放时间和预约方式。
- 人工咨询方式。

填写实际资料后点击「保存当前景区资料」；底部的「保存设置」也会保存已修改的景区资料。看到保存成功提示后，新内容会在下一次开始对话时生效。保存失败会保留输入供修改，不会把未保存内容当成生效资料。

当前已使用真实资料，不勾选虚构演示标记。更换景区时应完整替换简介、景点、路线与服务信息，不能只改名称。填写的景点与路线均应属于当前景区；只有测试虚构内容时才勾选演示标记。

讲解规则由本机服务按当前景区资料建立：先简短介绍、按问题展开、适配孩子的理解程度；资料缺失时引导人工确认，不声称看到游客所在位置或已经完成预约、登记、下单。资料保存在 `.private/guide-scenes.json`，与已有密钥、音色配置分别存放，网页不能直接读取这个私有文件。

旧版资料自动迁移到单一旅游景区版本：保留已有山水景区（scenic）资料，原三套资料的完整文件先备份为 `.private/guide-scenes.before-single-tourism.<随机编号>.json`，不向网页公开。所有旧选择归到唯一的旅游景区入口；原第二、第三套资料可从备份取回，不会作为当前景区事实使用。数据损坏时显示读取错误，不覆盖原件。尚未刷新的旧页面需要 Ctrl+F5。

## 当前实现范围与验证

这是旅游景区的本机功能演示，景区知识采用有长度限制的文本资料随每次语音会话加载。尚未加入文档上传检索、实时地图、票务或预约工具。既有照片动效仍有真实感限制，本轮没有更换人像、音色或人脸模型。本机人脸模型的既有个人与研究用途限制仍然适用，商业景区部署需要另行解决模型许可。

检查覆盖单一入口、资料保存与刷新恢复、非法资料和旧场景 ID 拒绝、保存时释放旧麦克风、保存失败保留输入，以及真实本机 WebSocket 桥接将统一景区资料送入受控上游。迁移检查覆盖 schema1/2 原件备份一致、山水资料保留、重复读取不重复迁移、损坏资料保护与私有备份不可通过网页读取。云端模型在这些测试中由受控服务代替，未新增实际云端问答、计费请求或现场麦克风采集。

2026-10-10 真实景区资料接入后的相关检查通过：13 项后台测试、9 项 Chrome 浏览器测试，包含官方来源关联、过期公告隔离与真实资料送入受控语音上游。没有新增实际云端问答或现场麦克风采集。

本机展示核验报告为 `output/guide-scenes/verification.json`，统一入口、设置与移动布局截图保存在同一目录。本次旧演示资料替换记录为 `output/chengde-guide/apply.json`，替换前原件备份在 `.private/guide-scenes.before-chengde.<随机编号>.json`。先前 schema1/2 合并迁移的历史报告仍为 `output/single-tourism-migration/verification.json`。核验确认照片哈希、原复刻音色、纯语音界面和已移除的 ChatGPT 会员连接保持当前状态；页面核验不保存或修改景区设置。
