## 打开与使用

本次加入照片局部的手腕动作：回答实际播放时，交握的双手会缓慢轻抬、倾转；插话、停止或关闭动效时恢复原照片。听话时增加一次轻微点头。最新修正让状态条位于照片外，移除底部遮罩、加强网页中可见的动作，并让轻声回答也能触发；短暂缺帧不会反复重启动作。修复音频仍有少量缓冲时被额外插入静音的问题，保留你的复刻音色。手部使用小区域 WebGL 绘制，不新增云端服务或实时神经模型；这是照片局部变形，不能张开交握手指、挥手或生成未拍到的姿势，也不能据此宣称真人级全身动作。口型仍为20FPS，之前反馈的整体卡顿尚未完全解决。音色相似度与听感仍需要实际试听确认。

## 当前语音链路

浏览器麦克风 → 本机 faster-whisper 中文识别 → ChatGPT 回答 → 本机 OpenVoice 合成及音色转换 → 浏览器声音播放。

音色固定取自 `public/assets/voice-reference-clean.wav`，生成的是新的回答，回答长短不受参考录音时长限制。仅向浏览器返回完成音色转换的声音；转换失败会提示错误，不播放另一种声音。

本机识别及合成使用 CPU，模型常驻。语音回答优先使用账号可用目录中的 `gpt-6-luna`，减少推理等待，先合成、播放短句，再合成后续内容；第一段转换可以与模型生成同时进行。只有模型正式完成回答后才播放声音。当前电脑仍有明显等待，后段音频未合成完时也可能短暂停顿。头像仍是二维照片和声音响应动效，尚未实现写实视频、口型同步或表情驱动。

这条本机测试链路使用 ChatGPT 授权的文字推理能力，本机完成语音识别和合成。原有独立 Realtime / Custom Voice 接口代码保留，需单独配置服务端凭据和专属 voice ID，当前本机语音链路不依赖该配置。

## 数据与运行

服务仅绑定 `127.0.0.1`。麦克风音频及音色参考在本机处理；识别的问题文字、必要的对话历史与角色设置发送给 OpenAI。实时录音不持久保存，转换中间文件用后清理。原始录音和降噪素材保留。

登录资料由 Windows CurrentUser DPAPI 加密保存在 `.private/chatgpt/`；浏览器拿不到令牌，项目不读取 Codex 或其他应用的登录资料。模型、Python 环境及第三方源码位于 `.runtime/`，均不对网页公开。

当前面向本人 Windows 本机测试。企业接待及公开服务部署需要另行接入获准的企业服务、知识库和客户留资流程。
